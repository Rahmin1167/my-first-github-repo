To Open a Project in Github, the steps to be done - 1.git init- To initialize a repository git creates a hidden directory called git. That directory stores all of the projects and refs that git uses. 2.git add[file name]- selects the file and moves it to the stage area, marking it for inclusion in the next commit. 3.git commit-m"message"- This command captures a snapshot of the project's currently saved changes and saves the commit message. 4.git branch-M main- creates a new branch "main". 5.git remote add origin [url]- When you execute the command you are specifying the url of the remote repository you want to connect to and giving it the name "origin". 6.git push-u origin main-This command is used in Git to push the local branch "main" to the remote repository named "origin".
